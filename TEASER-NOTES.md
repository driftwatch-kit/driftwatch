# Driftwatch teaser (public-repo safe)

These files are **examples**, not the product.

You may copy them into a public repository with the notice on each file left
intact. They are shorter and weaker than the paid pack on purpose: no CI
checker, no evals, no full rule set, no Claude/AGENTS discipline pages.

The full kit lives in the parent tree:

- `.cursor/rules/*.mdc` — seven enforceable rules
- `AGENTS.md`, `CLAUDE.md`
- `action/` + `src/driftwatch/` GitHub Action
- `evals/` fixtures and runner

See `../README.md` for pricing. This folder is not a license to republish
the rest of the pack.

Notice to paste alongside a teaser rule in a public repo:

> This is a Driftwatch teaser rule, not the full kit.
